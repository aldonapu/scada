# SCADA Web Monitoring System

A web-based **SCADA (Supervisory Control and Data Acquisition)** system designed to monitor and visualize the status of **Cranes, Stations, Conveyors, and PLCs** through a modern web interface.

This project is built with **React.js** and integrates with APIs to retrieve and display real-time industrial equipment data.

---

## 🚀 Features

* 📊 **SCADA Dashboard**

  * Real-time equipment monitoring
  * Overview of the entire system
  * Visual status indicators

* 🏗️ **Crane Monitoring**

  * Monitor crane status
  * Driver Running status
  * Connection status
  * Online status
  * Running status
  * Error status
  * Store In / Store Out monitoring

* 📍 **Station Monitoring**

  * Monitor station status
  * Store In status
  * Store Out status
  * Real-time station monitoring

* ⚙️ **PLC Monitoring**

  * Display PLC data
  * Monitor equipment based on index
  * API integration for PLC data

* 🚚 **Conveyor Monitoring**

  * Conveyor visualization
  * Conveyor status
  * Conveyor movement animation based on API data

* 💡 **LED Status Indicators**

  * Running
  * Online
  * Connected
  * Error
  * Warning

* 🔄 **Real-Time Data**

  * Periodically retrieves data from the API
  * Automatically updates equipment status
  * No manual page refresh required

* 📱 **Responsive Interface**

  * Designed for desktop and different screen sizes
